微光社区 · Lumina Commons  使用说明
================================================
（这是一个纯本地的网页演示项目，无需联网即可运行；只有「AI 寻友」接大模型时需要联网。）


一、怎么打开（3 步）
------------------------------------------------
1. 把整个文件夹解压到任意位置。
   建议路径不含中文和空格，例如：D:\LuminaCommons

2. 双击文件夹里的  「启动服务器.bat」

3. 稍等一两秒，浏览器会自动打开首页：
       http://127.0.0.1:8000/index.html
   如果没自动打开，就把黑窗口里显示的那个地址，手动复制到浏览器地址栏。

   注意：那个黑色命令行窗口要一直开着，关掉服务就停了；
        想停止运行时，关掉黑窗口或在窗口里按 Ctrl+C。


二、运行环境要求
------------------------------------------------
· 操作系统：Windows
· 需要安装 Python 3（任意 3.6 以上版本；安装时务必勾选
  “Add Python to PATH”）
  下载：https://www.python.org/downloads/windows/
· 浏览器：Chrome 或 Edge（建议较新版本）


三、为什么必须用「启动服务器.bat」，不能直接双击 html
------------------------------------------------
本项目使用了浏览器的 ES Module 技术，直接双击 html（file:// 方式）
会被浏览器安全策略拦截，页面会白屏。
必须通过本地服务器（http:// 方式）打开。
「启动服务器.bat」就是帮你一键起这个小服务器的。


四、各个页面介绍
------------------------------------------------
· 首页            index.html      社区漫游视频（自动播放，可点画面开启声音）
· 3D 沙盘         sandbox.html    社区 3D 全景：点建筑看分区、投稿搭子帖、
                                  左下角「AI 寻友」助手
· 技能广场        skills.html     各分区成员工牌墙、搭子帖信封墙、发布技能帖
· 个人中心        profile.html    填写名片、选/上传头像、技能与空闲时间、我的关注

顶部导航栏在这几个页面之间切换。


五、AI 寻友 · 接入大模型（可选）
------------------------------------------------
不配置也能用（走本地关键词匹配）；配置后会真正调用大模型来理解问题、生成回答。

步骤：
1. 进入「3D 沙盘」页 → 左下角「🤖 AI 寻友」面板 → 点右上角  ⚙️
2. 填写三项，然后点「保存并启用」，再点「测试连接」确认连通：

   接口地址：https://api.deepseek.com/chat/completions
   模型名  ：deepseek-flash        （或能力更强的 deepseek-v4-pro）
   密钥    ：你自己的 DeepSeek API 密钥（sk- 开头）

   —— 用其它家也可以（OpenAI 兼容接口）。例如通义：
   接口地址：https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
   模型名  ：qwen-plus

3. 回到输入框提问即可，例如「有没有人打排球」「怎么学吉他入门」。

重要提醒：
· 模型名必须一字不差，写错会提示「模型不存在」。
· 密钥只保存在这台电脑的浏览器里（localStorage），换电脑要重新填。
· 如果测试连接提示跨域（CORS）失败，说明该服务商不允许网页直连，
  需要自建一个中转服务，或换用允许直连的服务商。


六、常见问题
------------------------------------------------
· 页面白屏 / 打不开
  → 一定是没走服务器。请用「启动服务器.bat」，不要直接双击 html。

· 提示找不到 Python
  → 没装 Python 3，或安装时没勾选 Add to PATH。装好后重新运行 .bat。

· 端口 8000 被占用
  → 脚本会自动改用 8080 / 8088 等端口并打印实际地址，按窗口里显示的地址访问即可。

· 3D 沙盘加载慢 / 一直转圈
  → 首次进入要加载约 40MB 的模型文件，属于正常，请耐心等待。

· 控制台有字体 404（mifu.woff2 / mifu.ttf）
  → 这是可选的装饰字体，随包未附带，不影响任何功能，忽略即可。

· AI 寻友回复显示「大模型调用失败」
  → 看提示里的具体原因：模型名写错 / 密钥无效 / 网络或跨域问题。

· 换电脑后之前的资料没了
  → 正常。所有数据都存在各自电脑的浏览器本地，不会随文件夹一起带走。


七、数据说明
------------------------------------------------
名片、技能、关注、帖子、AI 配置等数据，全部保存在「本机浏览器」的
localStorage 里，不上传任何服务器。换电脑或换浏览器都是全新的空白数据。


八、目录结构（主要）
------------------------------------------------
  index.html / sandbox.html / skills.html / profile.html   四个主页面
  css/          样式表
  js/           逻辑代码（含 ai.js 大模型接入、store.js 本地数据）
  assets/       视频、3D 模型、图片素材
  three_lib/    3D 引擎（three.js，本地版，无需联网）
  serve.py      本地服务器脚本
  启动服务器.bat  一键启动（双击它）
